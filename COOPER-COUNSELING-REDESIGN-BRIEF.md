# Cooper Counseling LLC — Website Redesign Brief

Source reviewed: https://www.coopercounselingsc.com/ (Home, About, Contact, and Resources), September 4, 2026.

## Brand foundation

- **Business:** Cooper Counseling LLC
- **Clinician:** Patricia “Tricia” Cooper, LCPC, LPC
- **Phone:** 406-534-5477
- **Positioning:** Evidence-based OCD and anxiety treatment, currently telehealth only.
- **Licensure/markets:** Montana, Alaska, and South Carolina. The home-page headline currently says “OCD and Anxiety treatment from Montana to South Carolina.”
- **Voice:** Calm, warm, direct, encouraging, and clinically confident. The existing writing uses approachable language (for example, “I’m so glad you are here”) alongside clear treatment expertise.

### Existing visual language

- Minimal, airy, white-forward layout.
- Pale aqua/mint is the signature accent; the resource page uses a very light blue-green field.
- Fine-weight, highly letter-spaced uppercase display typography; body copy is clean and friendly.
- Current Wix fonts: `brandon-grot-w01-light` and `avenir-lt-w01_35-light`.
- Nature imagery supports a calm, reflective mood (pier/water scene), while the clinician portrait adds trust and warmth.

For the redesign, retain the mint/seafoam feeling but use accessible contrast for text and calls to action. The current palette is useful as a mood direction, not a verified color specification.

### High-value SEO improvements

- Add a unique, descriptive title tag and meta description to every page. The current audited pages have no meta description.
- Create dedicated **Services**, **Telehealth & States Served**, and **ERP for OCD** pages rather than relying only on home-page sections.
- Use one plain-language H1 per page; retain treatment acronyms but define them on first use.
- Add organization, therapist/person, local-business/service, and FAQ schema only after validating all factual details.
- Add readable alt text to the logo, clinician portrait, and purposeful imagery; avoid generic image filenames as alt text.
- Add an accessible crisis message and an emergency disclaimer on Contact/Resources, reviewed by the clinician.

## Navigation and conversion recommendation

Recommended primary navigation: **Home · Meet Tricia · OCD & Anxiety Therapy · ERP · Telehealth & States Served · Resources · Contact**.

The primary CTA should be consistently worded: **Schedule a free 15-minute consultation**. Repeat it in the hero, after services, and at the end of the About page. Keep the contact form simple, but add response expectations and a privacy-aware note before collecting messages.
